Icons

The 188 icons bundled with this template, from Lucide. Click any icon to copy its name.

Using an icon

Write a placeholder element and the icon is swapped in at boot. Size and colour come from Tailwind classes.

<i data-lucide="shield-check" class="size-4 text-muted-foreground"></i>
size-3.5 size-4 size-5 size-8 --primary --success --destructive

Only the icons listed here are bundled — the set is curated in src/js/modules/icons.js so the payload stays small. To use another of Lucide's 1,500+ icons, import it there first; referencing one that is not imported renders nothing.
